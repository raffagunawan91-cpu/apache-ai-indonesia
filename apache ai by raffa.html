Pengguna mengatakan tidak bisa masuk ke website Apache AI. Mari saya analisis kemungkinan penyebabnya:

  1. Loading screen tidak hilang - Mungkin timeout atau error JavaScript
  2. Tombol login tidak berfungsi - Mungkin event listener tidak terpasang
  3. Firebase error - Jika Firebase SDK tidak dimuat tapi kode mencoba mengaksesnya
